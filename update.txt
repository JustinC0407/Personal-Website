Pixel-World Portfolio Update

Completed work
- Scaffolded a Next.js, TypeScript, and Tailwind portfolio app from the README brief.
- Added JSON-driven content for about, skills/education, projects, creative work, contact, and world scenes.
- Built standalone portfolio routes for About, Skills/Education, Projects, Creative, Contact, and detail pages.
- Redesigned the homepage into a Stardew-inspired title screen with the custom fonts:
  - svboldhu.ttf for large/title text.
  - stardew-item-font.ttf for smaller UI/body text.
- Hid the normal navbar on the homepage and world page.
- Converted homepage shortcut buttons into large in-page popups instead of navigating away.
- Built a shared PortfolioModal component used by both the homepage and world mode.
- Rebuilt /world as a full-screen game-style scene instead of a boxed console.
- Added smooth requestAnimationFrame-based movement with WASD/arrow controls.
- Removed desktop click-to-move.
- Added mobile drag-anywhere movement.
- Added hard-centered camera follow with map-edge clamping.
- Added in-world hamburger menu, back-to-start button, proximity prompts, and debug toggle.
- Added world zoom controls under the scene label in the top-right corner.
- Changed world hotspots so About, Projects, Creative, and Contact open full-screen popups instead of routing away.
- Kept house door/exit hotspots as scene transitions.
- Replaced the blue JC player block with animated directional character sprites.
- Added walking animation that cycles stand -> 2 -> stand -> 4 while moving and returns to stand when idle.
- Scaled the player sprite art for the world scene and added a small ground shadow under the character.
- Tightened the player hitbox to better match the visible sprite instead of the old square footprint.
- Replaced the outside placeholder block layout with layered world artwork:
  - world_background.png as the base scene.
  - world_background_ontop.png as the top overlay layer.
- Changed the world scene to the outside art's native 1600x900 size and rescaled the world JSON coordinates to match.
- Added support for mixed collision shapes:
  - rectangle collisions for walls, roots, beds, and blockers.
  - ellipse collisions for rounded lake/water blockers.
- Retuned the outside world collisions and temporary outside hotspots against the new art.
- Added tree-root blockers so the player can walk behind tree canopies but not into the exposed roots.
- Added curved lake blockers with an opening across the bridge so the player can cross only at the bridge area.
- Added debug rendering for ellipse collisions and yellow depth-zone overlays.
- Added data-driven depth zones so entering a yellow-box area changes whether the outside top overlay renders in front of or behind the player.
- Fixed a z-index bug where the depth zone was active but the overlay still rendered above the player.
- Fixed a malformed ellipse/rect collision entry that caused a NaN debug-style console error.
- Fixed extension-caused hydration warning on the root body.
- Fixed modal scrolling so content scrolls below the header instead of sliding behind it.
- Fixed the homepage height after navbar removal so the global background grid no longer shows at the bottom.
